# 🚀 Telegram Media & Message Manager

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg?logo=python&logoColor=white)](https://www.python.org/)
[![Telethon](https://img.shields.io/badge/Telethon-1.36+-informational.svg?logo=telegram&logoColor=white)](https://github.com/LonamiWebs/Telethon)
[![tqdm](https://img.shields.io/badge/tqdm-Progress%20Bar-green.svg)](https://github.com/tqdm/tqdm)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Универсальный и быстрый асинхронный инструмент на Python для скачивания медиафайлов, просмотра, поиска и сортировки сообщений из каналов и чатов Telegram с удобным интерактивным консольным интерфейсом.

---

## 🌟 Основные возможности

- 📥 **Скачивание любых медиафайлов:**
  - Фотографии (`photos/`)
  - Видео и видеосообщения/кружочки (`videos/`)
  - Музыка и аудиозаписи (`audio/`)
  - Голосовые сообщения (`voice/`)
  - Документы, PDF, архивы и любые файлы (`documents/`)
- 📁 **Автоматическая структуризация:** все файлы распределяются по папкам канала и категориям.
- ⚡ **Умный пропуск (Smart Skip):** если файл уже был скачан ранее, скрипт мгновенно пропускает его, экономя время и трафик.
- 📊 **Прогресс-бар `tqdm`:** наглядная шкала прогресса со статусом загрузки каждого файла и итоговой сводкой.
- 📋 **Просмотр и сортировка сообщений:**
  - По дате (сначала новые или сначала старые).
  - По типу контента (фото, видео, аудио, документы, текст).
  - По размеру файла (от самых больших к меньшим).
- 🔍 **Поиск по сообщениям:** фильтрация и поиск по ключевым словам и фразам.
- 🔄 **Интерактивное консольное меню:** непрерывная работа без необходимости перезапускать скрипт при каждой задаче.
- 🛡️ **Защита от лимитов (FloodWait):** автоматическая обработка пауз Telegram API.

## 🛠️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/YOUR_USERNAME/telegram-media-manager.git
cd telegram-media-manager
```

### 2. Создание и активация виртуального окружения
- **Windows:**
  ```powershell
  python -m venv .venv
  .venv\Scripts\activate
  ```
- **Linux / macOS:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка API Telegram
Откройте файл `main.py` и укажите свои данные от Telegram API (получить их можно на [my.telegram.org](https://my.telegram.org)):

```python
api_id = 12345678              # Ваш API ID
api_hash = 'your_api_hash'     # Ваш API Hash
phone = '+1234567890'          # Ваш номер телефона
```

### 5. Запуск
```bash
python main.py

py main.py
```

При первом запуске Telegram попросит ввести проверочный код из приложения (и пароль двухфакторной аутентификации 2FA, если он включен).

## 🖥️ Использование

После запуска скрипта откроется интерактивное меню:

```text
============================================================
🚀 TELEGRAM MEDIA & MESSAGE MANAGER
============================================================

📌 Текущий канал: @durov
--------------------------------------------------
1. 📥 Скачать медиа (фото, видео, аудио, документы и др.)
2. 📋 Просмотреть и отсортировать сообщения
3. 🔍 Поиск сообщений по ключевому слову
4. ℹ️ Информация о канале
5. 🔄 Сменить рабочий канал
0. 🚪 Выход из программы
--------------------------------------------------
```

### Форматы ввода каналов:
Скрипт понимает любые форматы:
- `@channelname`
- `channelname`
- `https://t.me/channelname`
- `t.me/channelname`
- Приватные ссылки приглашений (`t.me/+...` или `t.me/joinchat/...`)
